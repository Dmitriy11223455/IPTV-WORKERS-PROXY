# Cloudflare Worker IPTV Server

Легковесный IPTV-сервер, развернутый на базе Cloudflare Workers. Проект оптимизирован для бесплатного использования в кругу друзей или семьи с жестким контролем нагрузки для соблюдения лимитов платформы.

## 🚀 Особенности и ограничения

* **Cloudflare Workers**: Запуск в бессерверной (serverless) среде с минимальной задержкой.
* **Лимит подключений**: Сервер жестко ограничен на **10 одновременных пользователей** для экономии ресурсов.
* **Таймаут трансляции**: Сессия просмотра автоматически прерывается через **8 часов**, чтобы избежать фонового расхода лимитов (защита от «забытого включенным» ТВ).
* **100% Бесплатно**: Нет скрытых платежей, подписок и рекламы.
* **Формат плейлиста**: Генерация готового списка каналов в формате `.m3u` / `.m3u8`.

## 🛠 Технологический стек

* **Среда выполнения**: Cloudflare Workers
* **Язык**: TypeScript / JavaScript (Wrangler CLI)
* **Хранилище данных**: Cloudflare KV / Durable Objects (для подсчета активных сессий)

## 🔧 Развертывание (Deployment)

### 1. Клонирование и установка
```bash
git clone https://github.com<ваше_имя_пользователя>/<имя_репозитория>.git
cd <имя_репозитория>
npm install
```

### 2. Настройка `wrangler.toml`
Убедитесь, что в файле конфигурации `wrangler.toml` созданы необходимые пространства имен для хранения сессий (KV):
```toml
name = "my-iptv-worker"
main = "src/index.ts"
compatibility_date = "2026-01-01"

[[kv_namespaces]]
binding = "IPTV_SESSIONS"
id = "<ID_вашего_KV_на_Cloudflare>"
```

### 3. Публикация в Cloudflare
Авторизуйтесь в своей учетной записи и разверните воркер:
```bash
npx wrangler login
npx wrangler deploy
```

## 📺 Использование

1. Скопируйте URL вашего развернутого воркера: `https://my-iptv-worker.<ваш_субдомен>.workers.dev/playlist.m3u`
2. Вставьте эту ссылку в любой IPTV-плеер (VLC, OTT Navigator, Televizo).
3. **Важно**: Если в данный момент ТВ смотрят уже 10 человек, сервер вернет ошибку подключения (HTTP 429). Через 8 часов непрерывного просмотра плеер потребуется перезапустить через сутки.
